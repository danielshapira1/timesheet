# Timesheet App

A modern, responsive time tracking application built with React, TypeScript, and Tailwind CSS.

## Features

- **Dashboard (Home):** Overview of your time tracking entries.
- **Calendar View:** Visualize and manage your entries in a calendar format.
- **Add Entry:** Easily log new time entries.
- **Reports:** Analyze your time tracking data.
- **Settings:** Customize the application, including theme support (Light/Dark/System).
- **RTL Support:** Built-in Right-to-Left layout support.

## Tech Stack

- **Framework:** [React](https://react.dev/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Routing:** [React Router](https://reactrouter.com/)
- **State Management:** [Zustand](https://github.com/pmndrs/zustand)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Date Handling:** [Role-fns](https://date-fns.org/)

## Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd timesheet
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173` (or strictly the URL shown in the terminal).

### Building for Production

To create a production build:

```bash
npm run build
```

The build artifacts will be stored in the `dist/` directory.

### Preview Production Build

To preview the production build locally:

```bash
npm run preview
```
